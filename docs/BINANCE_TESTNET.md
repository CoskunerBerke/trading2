# BINANCE TESTNET (hazırlık — bu görevde etkinleştirilmedi)

- Gateway'ler (`execution/gateway.py`): `BinanceSpotTestnetGateway` (https://testnet.binance.vision), `BinanceFuturesTestnetGateway` (https://testnet.binancefuture.com). Yalnız `enabled=True` **ve** env anahtarları (`BINANCE_TESTNET_SPOT_KEY/SECRET`, `BINANCE_TESTNET_FUTURES_KEY/SECRET`) **ve** enjekte HTTP istemcisi ile çalışır; aksi hâlde `ExecutionDisabledError`. HMAC-SHA256 imza (Binance doküman vektörüyle test edildi), `recvWindow`, deterministik `newClientOrderId` (`tb-<env>-<strategy>-<SYMBOL>-<hash8>-<intent>-<seq>`, ≤36 karakter; retry aynı id).
- Order state machine (`execution/orders.py`): CREATED → RISK_APPROVED → SUBMITTING → ACKNOWLEDGED → PARTIALLY_FILLED → FILLED; CANCEL_REQUESTED → CANCELED; REJECTED/EXPIRED; SUBMITTING → UNKNOWN → RECONCILING (timeout'ta **asla** kör tekrar gönderim yok: önce clientOrderId sorgusu / açık emirler / fill geçmişi).
- Reconcile (`execution/reconcile.py`, `python -m tradingbot reconcile`): PAPER'da defter ↔ journal; TESTNET'te gateway pozisyonları/açık emirler ↔ yerel; mismatch → HALT_ALL (`RECONCILIATION_MISMATCH`).
- Geçiş: `python -m tradingbot mode-transition --to TESTNET --operator <ad> --check manual_config=true testnet_keys_present=true test_suite_passed=true health_ok=true`. Otomatik geçiş yok. Testnet kârlılık kanıtı değildir; emir yaşam döngüsü doğrulamasıdır.
- Resmî kaynaklar: https://developers.binance.com/en/docs (Spot testnet REST, USDⓈ-M futures market-data/account/trade, rate limits). Bu sürüm gerçek Binance emri göndermez; anahtar sohbet içinde istenmez.
